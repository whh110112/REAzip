# 皮肤与 A 方案自动标志

[English](themes.md)

窗口内的 A 标志自动读取当前皮肤，包括后续导入的自定义皮肤。无需单独选择 logo 配色、底纹、底色或比例。切换皮肤或重新扫描更新后的皮肤时，配色和背景随之更新；打开、切换压缩包时，圆环自动读取对应比例。

## 压缩比例与开口

保留比例 = 压缩包实际体积 ÷ 所有文件原始体积之和，不计目录。保留比例 60% 时，圆环保留 60%，开口占圆环面积 40%，对应 144°。有有效数据时采用径向端点，避免圆头笔画额外占用开口面积。

没有压缩包、正在读取、刷新失败、空包或元数据不完整时，显示 A 原稿的圆头默认开口（中心线 48°）。压缩包因文件头等开销大于原始文件时，显示完整圆环，后台仍保留真实比例。筛选、选择文件或进入子目录不改变整个包的比例。

固实压缩使用整个包的实际体积，不把缺失的逐文件压缩大小当成零。`.001` 分卷计入所有分卷体积；其他多卷格式需引擎提供完整总大小，否则保留默认标志。计算支持 64 位文件大小，原始文件总和超过单个无符号 64 位数时也不会整数回绕。

标题栏、欢迎页、归档详情、解压窗口、关于页共用同一组件。窗口系统图标、任务栏、安装器和操作系统关联使用固定比例，不会因为打开某个压缩包而改写注册信息或系统图标。

## 自定义皮肤约定

在“设置 → 外观”打开的皮肤目录内放入 JSON 文件。仅含 `vars` 的已有皮肤继续兼容；缺失的颜色参数按 `base` 从素纸或夜墨继承。

完整示例见[英文格式说明](themes.md)。皮肤作者可增加顶层 `background`：

```json
"background": {
  "pattern": "dots",
  "opacity": 0.10,
  "spacing": 16,
  "texture": "textures/paper.png"
}
```

- `pattern`：`none`、`dots`、`lines`、`grid`，默认 `none`。
- `opacity`：0–0.18，默认 0.10。
- `spacing`：8–64 个逻辑像素，默认 16。
- `texture`：可选的皮肤目录内相对路径，支持 PNG、JPEG、WebP，最大 4 MiB、4096×4096 像素。

图案颜色自动来自皮肤的次要文字色；背景纹理同时供内容区和标志使用。后续可在此约定下扩展图案类型，不增加单独的 logo 设置。外部路径、远程 URL、符号链接逃逸、无效参数会被忽略；不执行 SVG、CSS 或 JavaScript。纹理更新后重新扫描皮肤即可刷新。

logo 优先使用 `--accent`，对比不足则依次使用 `--accent-strong`、`--text`，最后自动选择黑或白。先合成透明色，再以线性 sRGB 相对亮度计算对比：普通尺寸目标 3:1，16–24 px 目标 4.5:1。带纹理时，圆环笔画下方自动增加窄的表面色衬底，周围仍保留皮肤纹理。小尺寸仅加粗笔画，不改变有数据时的扇区比例。

## 验证

原生 GUI 测试检查实际渲染的 60% 圆环面积、比例边界、六款皮肤、真实自定义纹理和低对比/透明色回退；控制器测试使用真实 worker 列表；引擎测试核对真实分卷的总体积。验收截图保存在 CI 附件中。

固定系统资源可通过 `python native/tools/generate-logo.py`（需要 Pillow）重新生成，包含 SVG、1024 px PNG 和七尺寸 ICO；生成后会重新打开 ICO 验证其尺寸。不修改已发布的 0.4.1 安装包。
