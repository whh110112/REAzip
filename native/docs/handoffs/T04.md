# T04 交接

实现：C++ worker使用QtCore的NDJSON私有管道，归档线程/控制线程分离；GUI JobController用QProcess和串行队列。每任务jobId、挑战challengeId，单一终态，最大16MiB帧，分块条目与十进制64位字节数。密码在管道传递，不放argv/日志/设置。归档路径在worker使用用户临时目录内的QLockFile排他锁，进程退出后释放。

本机 Windows x64：native-foundation、native-read、native-write、native-controller、native-worker五项全PASS（7.74s）。Controller测试经过真实JobController→worker→原生库，覆盖排队、密码和取消；协议测试覆盖缺/错密码重试、挑战期间取消、版本错误和非法JSON。提交阶段向GUI发committing状态；强制取消不终止已进入提交阶段的worker。

跨平台CI发现POSIX 7-Zip26.04默认强制UTF8，已加bootstrap/posix-codepage.inc显式GBK/Big5/Shift-JIS转码补丁。Linux x64/ARM64读取与写测试已通过。macOS编译发现libc++时间戳为更宽整数，现已显式转换为int64；修复待后续CI复验。Windows x64/ARM64也已通过core读取/写入回归。远程pipeline当前不包含Qt worker测试，T09需扩展。

限制：超长/半包/乱序挑战/突发进度压测还需补齐。强杀或断电后多卷持久恢复日志尚未具备，静态路径逃逸检查不是完整恶意并发攻击防护；这些保持发布阻塞，不宣称R16/R34全通过。具体安全增强由集成/验收收口。
