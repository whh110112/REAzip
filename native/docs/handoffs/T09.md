# T09 候选构建交接

原生候选版本统一来自 VERSION.txt。Native candidate workflow 为六个原生 runner 构建完整 Qt 应用/worker/7-Zip，测试后部署离线依赖并检查每个二进制 CPU；移除开发环境 PATH/QML/Qt 库路径后重新读取 ISO。每包提供源码 SHA、版本、架构、SHA256、签名状态、许可证/Qt SPDX、7-Zip原始源码和POSIX补丁、bit7z/ghc/应用对应源码。

产物矩阵：Windows x64/ARM64各安装EXE+便携ZIP；macOS x64/ARM64各DMG+ZIP；Linux x64/ARM64各AppImage+tar.gz+deb。Windows在GitHub临时runner额外静默安装→运行→卸载；默认不注册文件关联。Mac使用ad-hoc签名并验证，未公证；Windows未签名。Linux打包已带Qt运行库，无需用户安装Qt/Node/7-Zip。

完整六目标候选已通过：[run 39046385881](https://github.com/whh110112/REAzip/actions/runs/39046385881)，源码 d39681507ee7b037d616c36e7bb338e1194af7b8。六个原生runner和aggregate全部成功，包含10项CTest、真实GUI操作、包架构检查和隔离运行。Windows额外安装/运行/卸载通过，macOS两个架构DMG和ZIP均生成。T10安全增强后须用新SHA重跑，旧包不代表新代码已验收。此前Mac DMG Resource busy已由HFS+显式配置/有限重试修复；Windows ARM host Qt x64 DLL与CRT旁路文件混入已由target qtpaths和匹配CRT筛选修复。

本机Windows x64已产出完整安装EXE约26.7MB、便携ZIP约36.6MB、解包112.5MB；见 docs/size-and-performance.md 和原始记录。工作集减少但首帧没有证明更快，不做未经证实的性能宣传。
