# T07 系统集成交接

本机 Windows x64 CTest 8/8 PASS（17.13s）。平台测试在自建 HKCU/Software/REAzipTests 隔离子树验证原生注册API、带空格路径的引用、所有权检查和卸载不移除无关配置；没有修改开发账户的默认应用。子进程实际启动并经同用户本地管道转交 Unicode 文件请求，验证版本/路径校验和 portable.flag 路径。NTFS 来源流复制测试通过。真实 Qt 窗口 sample.iso smoke 无 QML 报错。

| 平台 | 实现 | 仍需环境验收 |
|---|---|---|
| Windows | argv、同用户单实例、HKCU Capabilities/OpenWith 注册、默认应用设置入口、经典静态右键菜单（打开/解压到/解压到当前目录/添加）、只卸载自有项 | 专用用户双击/Explorer 菜单与安装卸载；Win11 现代菜单未实现 |
| macOS | QFileOpenEvent、同用户 socket + getpeereid 校验、bundle DocumentTypes/UTI | Finder 冷/热启动、签名/公证与拖出；Finder 菜单扩展未实现 |
| Linux | argv、SO_PEERCRED 同用户校验、desktop MIME 声明，AppImage 使用永久 APPIMAGE 路径 | 各桌面双击/默认应用与拖出；Nautilus/Dolphin 扩展菜单未实现 |

数据路径：存在程序旁 portable.flag 时严格使用旁边 data；否则标准 AppDataLocation/native。实例锁/管道消息最大1MiB、3秒超时、128路径上限，仅本地绝对路径，不经shell。目录不可写不静默迁入其他位置。

拖出：选中条目后“准备拖出”经真实 worker 安全提取到受控临时目录；完成后拖动“拖出选中项”，QDrag 导出真实文件 URLs，只含本次选择，保留临时目录至进程结束。此实现已编译，实际桌面拖放仍待 T10 人工交互验收。

Windows MOTW：提取时在暂存文件提交前复制源归档 Zone.Identifier；复制失败则该文件不提交，不修改既有未选目标。双击脚本/程序/快捷方式另行提示，缺少来源也不静默执行。Linux/macOS 默认提取普通文件不授予可执行权限。macOS quarantine 保留策略仍需平台实测补齐。

T09 使用 native/platform/Info.plist.in，安装器可调用 --register/--unregister；不篡改 UserChoice。用户显式点击注册后才进行运行时关联。T08 接入便携数据服务，T10 必须保留尚未验证的系统级项。

参考：[Qt QLocalServer](https://doc.qt.io/qt-6/qlocalserver.html)、[Windows Default Programs](https://learn.microsoft.com/en-us/windows/win32/shell/default-programs)。
