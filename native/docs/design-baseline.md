# T00 视觉基线

来源提交 163e17a；原 renderer 为设计依据，根目录 shots 为历史参考，不把桌面背景收入新产品资产。

逻辑尺寸 1120×740，最小 880×560；标题36、标签36、工具栏56，13px平台系统字体。主结构：标题、标签、工具栏、面包屑、虚拟文件表、右侧详情、底部状态。

色值和6皮肤抽取至 design/tokens.json 与 themes/builtin.json。主按钮圆角胶囊、卡片9px/模态框圆角、细边框沿用样式表。QML不使用浏览器；窗口系统按钮和字体抗锯齿允许平台差异。

tools/capture-legacy.cjs 使用隔离配置生成应用内截图，输出 .native-build/baseline/<scale>。必须记录实际捕获倍率；缺少的场景/平台不能写成已检查。

验收场景：空窗口、demo归档、六主题、压缩、解压、设置；补充密码、覆盖、进度、RTL及各倍率由后续UI验收提供。实际图像与场景manifest为证据，不把截图清单视为运行证明。
