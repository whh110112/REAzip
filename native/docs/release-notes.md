# ZENzip 0.4.1

正式维护版本，包含 PR #3 与 PR #4 的界面修正。

- 设置页在 18 种语言和六套皮肤中支持长文本与滚动，恢复已保存的语言、编码和主题选中状态。
- 修正暗色模式下拉箭头对比度、阿拉伯语复选框留白及高字形输入框裁切。
- 标签文件名在文字区域内居中，关闭与新增图标统一尺寸；高度适应不同文字，长名称可悬停查看。
- README 明列 18 种语言；当前界面、说明和发行文件统一使用 ZENzip。旧配置、加密库及安装升级兼容保持有效。

Windows/macOS/Linux 均提供 x64 与 ARM64 包。各文件 SHA-256、源码提交和测试结果随 Release 提供，验收范围见[发布报告](../../docs/verification-0.4.1.md)。

Windows 包未代码签名；macOS 为 ad-hoc 签名、未公证。Win11 现代菜单、跨应用拖出优化、系统深浅色跟随和自动更新未在本版新增；macOS/Linux 密码库仍未接入系统密钥库。
