# ZENzip 当前状态

原生实现位于 `native/`，源码版本号以 `native/VERSION.txt` 为准；当前可下载版本以 GitHub 最新正式 Release 为准。

- 设置页：六主题、18 种语言、六个子页的布局及保存状态回显。
- 标签栏：文件名字体与图标居中、自适应字高、长名称提示及 RTL 点击。
- 文件冲突：逐个选择、全部覆盖，以及仅本次任务记忆跳过/重命名/覆盖。
- 关于：手动检查正式版更新、版本状态及官方下载入口。
- 发布门禁：六目标构建、CTest、隔离包运行、安装/卸载检查及产物哈希。
- 当前验收范围见[报告](acceptance-report.md)，待办见[下一步](next-tasks.md)。
