# T00 行为规格

归档用稳定索引选择；同名条目保留独立ID，刷新后旧ID失效。目录包括所有后代。拖入/系统打开/菜单打开归档均走同一打开流程。

解压：所有路径经原生文件系统API处理。智能模式仅在归档没有唯一顶层目录时增加同名目录；多选和整包使用相同覆盖策略。询问未收到答复不写入，关闭即取消。Skip不改变已有文件，Rename不覆盖任何文件。

密码：缺密码进入可取消挑战；错误可重试；关闭不等于空密码。凭实际元数据显示算法，未知显示未知。密码不写设置、日志或命令行。

创建：输入相对路径映射明确；ZIP AES显式选择，7Z可加密文件头；TAR/TGZ不支持密码时禁用。TGZ最终解出真实文件。新建/修改先暂存验证后提交；错误与取消保留原包。源删除仅在已验证输出后，源变化/遗漏/取消不删源。

关联：冷/热启动都接收路径；系统默认应用尊重用户选择。便携模式带data目录，安装模式用标准用户目录。原生路径不可写时明确提示。

所有行为是新实现的明确规格，未实测的Bandizip内部规则不声称已还原。
