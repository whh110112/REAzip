# ZENzip 后续改进

以 main 和当前正式版的[验证报告](../../docs/verification-0.4.1.md)为基线。

1. 可配置临时盘、拖出前的展开大小估算、空间不足处理和安全回收。
2. Explorer、浏览器、图片编辑器和第三方文件管理器之间的真实拖放兼容性。
3. Windows 11 现代菜单的独立原生扩展与安装/卸载验收。
4. 系统深浅色跟随、高对比度、键盘与屏幕阅读器。
5. 18 种语言的母语审校、诊断消息本地化及字形检查。
6. macOS Keychain / Linux Secret Service；真实大包和海量文件性能基准。

此前磁盘满、设置布局和标签栏的修正不表示上述工作已经完成。功能边界见[已知限制](known-limitations.md)。
