# T08：设置、皮肤、语言与旧数据迁移

## 依赖 / 范围

依赖 T00/T01，按冻结主题接口可与 T05 并行。负责 native/settings、native/i18n、native/themes、tests/settings；不争改 UI 主组件。

## 实施

1. C++ 设置服务具备 schemaVersion、默认值、类型/范围校验、原子写入和损坏配置恢复。设置路径由 T07 提供。
2. 读取旧 Electron 设置的白名单字段：主题、语言、目录、恢复标签、编码等，做幂等迁移并保留原文件备份。不修改旧应用数据，不迁移密码。
3. 将 18 语言现有 key 映射到统一翻译服务，保持 key 稳定；采用 Qt 翻译或 JSON 翻译的明确一种方案，不两套并存。记录现有漏译、fallback 与修正。
4. 6 内置皮肤转换为结构化 token，特殊 CSS 效果由 T05 用 QML 组件等效表达。不得因为 CSS 不可执行而删掉所有自定义主题功能。
5. 自定义主题 JSON 保留 id/name/base/author/vars 能迁移的值；转换 CSS 颜色/rgb/rgba 等到 Qt 可接受值，进行边界校验。
6. 任意追加 CSS 无法无损移植：备份原文件、列出忽略项，在导入反馈里明确说明；绝不执行任意 QML/脚本作为替代。
7. RTL 与长译文样本对接 T05；主进程错误和系统对话框也本地化。版本/引擎信息取真实 identity。
8. 便携迁移、目录失效、主题损坏、语言包缺项、恢复标签指向加密包等要有一致交互。

## 验收

R18/R22/R23/R24/R32。旧配置至少 3 类样本：正常、字段不合法、文件损坏；重复导入不丢数据。18 语言 key 数量和缺项有自动检查，6 主题有实际 UI 截图。
