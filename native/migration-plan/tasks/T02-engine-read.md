# T02：原生归档读取、元数据、密码和编码

## 依赖 / 范围

依赖 T01。负责 native/engine/read、tests/engine-read，使用公共接口。不得改 UI、worker 协议和打包脚本。

## 实施

1. 用 bit7z/7-Zip 真实接口完成格式识别、列表、完整性测试和能力查询，禁止解析 7z 命令行输出。
2. 返回稳定条目 ID、原始索引和路径元信息；保留重复名称，兼容隐式目录、空包、非标准扩展名、损坏包、分卷首卷与缺卷。
3. 密码通过回调/请求入口注入。明确缺密码、错密码、损坏三类；不能等待控制台输入，空密码与用户取消语义分开。
4. 展示真实加密方法；未知就 unknown，ZIP encrypted 标记不等于 AES。不要根据文件扩展名强行断定格式。
5. 支持旧 ZIP 编码参数：Auto、GBK、Big5、Shift-JIS、UTF-8。验证锁定版本的真实 API，不存在时记录引擎扩展点并实现明确适配；不得用改显示名来伪装正确解压路径。
6. 条目列表按块发出，允许取消/错误；用 uint64/可选值处理大文件与未知 packedSize。
7. 限制内存和解析异常的影响，原生错误映射公共错误码，诊断中不包含密码。

## 验收

R02/R03/R04/R05/R06/R09/R11/R12/R32。测试须验证路径和内容/元数据，不只验证不抛异常。使用自建加密文件头样本证明缺密码会返回挑战而非挂起。代码页必须使用真实旧编码字节样本。

列出只读格式与可写能力，为 T03/T06 提供禁用依据。每种声称支持格式至少有代表样本，否则标记未验证。
