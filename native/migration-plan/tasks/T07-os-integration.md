# T07：系统打开、关联、菜单与便携路径

## 依赖 / 范围

依赖 T01 平台接口，可与引擎/UI 并行。负责 native/platform、tests/platform；与 T08 共享便携路径语义，与 T09 共享安装/卸载入口。

## 实施

1. Windows/Linux argv、macOS QFileOpenEvent/系统文件打开；冷启动和运行中均能转交归档路径。单实例协议限制同一用户、消息大小与来源，不经过 shell 拼命令。
2. Windows 使用受支持的原生注册 API 和应用注册机制，默认优先每用户安装；不沿用现有 PowerShell 文本拼接。注册打开命令正确处理空格/Unicode/引号，系统默认应用选择由用户完成。
3. macOS 配置 CFBundleDocumentTypes/UTI 和事件处理；不依赖最终用户另装 duti 才能被系统识别。
4. Linux 正确生成 desktop/MIME 集成；安装版与 AppImage 路径分开，不能把临时挂载路径持久化成 Exec 目标。
5. 系统菜单先定义清晰能力矩阵：Windows 经典菜单为首轮最低要求；Win11 现代菜单需真正的受支持扩展集成及打包验证，不能把经典菜单说成现代菜单。macOS/Linux 的 Finder/桌面菜单扩展明确受桌面环境和安装方式限制。
6. 支持打开、解压到指定目录、解压到同名目录、添加到压缩包等明确动作；系统传参同样经过请求校验和安全路径处理。
7. 定义便携标记文件与标准用户目录；便携版设置/主题放程序旁 data 目录，目录不可写时提示可操作解决方法；不要偷偷退回 AppData 后仍声称完全便携。
8. 与 T06 实现文件显示、原生对话框与拖出文件；Windows MOTW/来源信息处理策略要文档化并测试，不能因临时解压无意丢失必要安全提示。
9. 关联/菜单卸载只删除属于 REAzip 的注册，不覆盖其他应用后来接管的配置。

## 验收

R19–R22/R28/R31。关联、默认应用与卸载测试在专用用户或 VM 执行；证明用户双击的文件确实进入正确标签，而非仅注册表出现键值。测试错误路径、跨实例参数、多文件参数、Windows 路径空格和 Mac Finder 打开。
